Entrar

O painel salva as imagens no repositório do site no GitHub. Para isso ele precisa de um token de acesso seu, que fica guardado só neste aparelho.

Como criar o token (2 minutos)
  1. No GitHub, abra Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories → Desaposta.
  3. Em Permissions → Repository permissions, deixe Contents como Read and write.
  4. Clique em Generate token, copie e cole aqui.
