# Depoimentos do carrossel

Toda imagem desta pasta aparece no carrossel da página, sozinha.

**Para adicionar:** no GitHub, abra esta pasta → **Add file → Upload files** → arraste as imagens → **Commit changes**.
Em cerca de 1 minuto o site já mostra as novas imagens.

**Para remover:** abra a imagem aqui no GitHub → menu **⋯** → **Delete file** → **Commit changes**.

**Ordem:** segue o nome do arquivo. Para escolher a ordem, comece o nome com número: `1-joao.png`, `2-maria.png`, …

Formatos aceitos: PNG, JPG e WebP. As imagens são reduzidas automaticamente para carregar rápido no celular.
